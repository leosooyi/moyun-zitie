# 墨韵字帖

> 历代碑帖浏览与字帖生成工具，毛笔钢笔练字必备

## 项目简介

墨韵字帖是一个基于网页技术开发的书法学习工具，收录了大量历代经典碑帖、钢笔字帖和春联字帖，支持在线浏览、高清查看和字帖生成打印。应用采用纯前端技术实现，无需后端服务器，可直接在浏览器中运行，也可打包为安卓APP或PWA应用。

## 功能特性

### 📚 碑帖库
- 收录 **213本** 历代经典碑帖
- 覆盖楷书、行书、草书、隶书、篆书、魏碑、小楷等书体
- 从先秦到近现代，涵盖各朝代名家法帖
- 高清原貌呈现，支持放大查看

### ✒️ 钢笔字帖
- 收录 **146本** 硬笔经典字帖
- 以硬笔临古帖和公有领域硬笔书法为主
- 涵盖楷行草隶篆各书体
- 适合日常临摹练习

### 🧧 春联字帖
- 收录 **122本** 春联名帖
- 曹全碑、乙瑛碑、礼器碑、张迁碑、史晨碑、华山碑等汉隶集字春联
- 涵盖各书体与经典联语
- 可直接参考书写

### 🎨 字帖生成器
- 输入文字，一键生成可打印的练字帖
- 支持田字格、米字格、回宫格、空白格四种格子样式
- 支持毛笔/钢笔两种练习模式
- **17种字体**：楷书类（楷体、宋体、仿宋、中宋、细黑）、行草类（行书、行楷、草书、狂草、毛笔楷书、新魏）、隶篆类（隶书、汉隶、小篆、大篆、金文、九叠篆）、装饰类（黑体、幼圆、琥珀、姚体）
- 字号比例、字重可调
- 描红模式：全黑字、首行描红、全描红、空白临帖
- 支持打印/导出PDF

### 📱 多端适配
- 响应式设计，电脑手机均可使用
- 支持PWA，可添加到手机主屏幕
- 可打包为安卓APK安装包

## 使用方法

### 电脑端直接使用
1. 双击打开 `墨韵字帖.html`
2. 顶部导航切换碑帖库/钢笔字帖/春联字帖/字帖生成
3. 点击卡片查看高清大图
4. 字帖生成器输入文字，选择格式，点击生成

### 手机端使用（PWA）
1. 将项目部署到静态托管服务（Netlify/GitHub Pages/Vercel）
2. iPhone用Safari打开网址 → 分享 → 添加到主屏幕
3. 安卓用Chrome打开 → 自动提示安装应用

### 安卓APP
详见 `android_app/构建说明.md`，使用Android Studio构建APK。

## 部署方式

### 方式一：Netlify Drop（最简单）
1. 打开 https://app.netlify.com/drop
2. 将整个项目文件夹拖入
3. 获得网址，即可访问

### 方式二：GitHub Pages
1. 创建GitHub仓库，上传所有文件
2. Settings → Pages → 选择main分支
3. 获得 `https://用户名.github.io/仓库名/墨韵字帖.html`

### 方式三：Vercel
1. 打开 https://vercel.com
2. 上传项目文件夹
3. 自动部署获得网址

## 技术栈

- **前端**：原生 HTML5 + CSS3 + JavaScript（无框架）
- **字体**：Google Fonts / Fontsource CDN（草书、行书、小篆等书法字体）
- **PWA**：Service Worker + Web App Manifest
- **安卓**：WebView + Android Studio
- **数据**：静态JSON数据，内嵌于HTML中

## 字体说明

应用使用以下字体，均为免费可商用：

| 字体 | 来源 | 说明 |
|------|------|------|
| 崇羲篆体 | Fontsource CDN | 小篆字体，以《说文解字》为依据 |
| 刘建毛草 | Fontsource CDN | 草书字体 |
| 龙藏 | Fontsource CDN | 狂草字体 |
| 志莽行 | Fontsource CDN | 行书字体 |
| 马善政 | Fontsource CDN | 毛笔楷书 |
| 站酷小薇 | Fontsource CDN | 古风字体 |
| Noto Serif SC | 飞书字体CDN | 宋体 |
| 系统字体 | 本地 | 楷体、黑体、隶书等 |

> 小篆、草书等字体通过CDN加载，首次使用需联网，之后浏览器缓存。也可安装本地字体（如华瑞小篆体、方正小篆体），应用会自动优先使用。
